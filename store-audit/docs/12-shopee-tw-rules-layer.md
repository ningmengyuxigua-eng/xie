# Shopee 台灣官方規則層

## 目的

所有商品、廣告、促銷、訂單與店鋪表現建議，都必須先通過 Shopee 台灣站官方規則檢查。規則層保存來源、版本、檢查日期、生效狀態及受影響模組，避免使用過期規則。

## 規則來源優先級

1. Shopee 台灣幫助中心的條款、政策及服務規範。
2. Shopee 台灣賣家中心公告與賣家學習文章。
3. 賣家中心目前顯示的營運表現、違規及活動資格。
4. 系統自行計算的經驗指標只能標記為 `empirical`，不得冒充官方規則。

第三方文章、社群貼文及未能核對日期的教學不能作為自動決策依據。

## 第一批官方規則分類

| 分類 | 系統要檢查的事項 | 影響模組 |
|---|---|---|
| 商品刊登 | 不正確關鍵字、重複刊登、誤導價格、外部交易引導、盜圖及仿冒 | 商品優化、下架候選、組合銷售 |
| 禁止與限制商品 | 商品是否允許販售，是否需要許可、檢驗或標示 | 商品上架、組合、廣告 |
| 智慧財產權 | 商標、圖片、描述及商品來源證明 | 商品內容、廣告素材 |
| 履約 | 備貨期限、遲延出貨、賣家取消及系統不成立 | 訂單提醒、店鋪健康 |
| 售後 | 退貨退款、商品與描述一致性 | 商品品質、店鋪健康 |
| 聊聊 | 回應率及回覆速度的公開表現 | 客服提醒、店鋪健康 |
| 活動與費用 | 優惠券、免運、蝦幣及活動資格與費用 | 定價、促銷、盈利分析 |

## 店鋪權重分析邊界

Shopee 未公開完整搜尋排序公式及各因素權重，因此系統不得輸出「某因素占權重百分之多少」的結論。分析分成兩層：

- `official_compliance`：官方明確公布或賣家中心直接顯示的指標，例如賣家計分、遲延出貨、不成立率、聊聊表現、評價、違規商品、活動資格及休假模式。
- `empirical_performance`：從本店歷史資料觀察的曝光、點擊率、轉換率、銷量、價格、庫存及內容品質訊號。這些只能用於相對比較和試驗，不能稱為官方權重。

店鋪健康報告先顯示官方合規紅線，再顯示經驗表現。官方規則衝突時，任何增長建議都必須被阻擋。

## 規則版本管理

每一條規則至少保存：

- `market = TW`
- `rule_id`
- `category`
- `title`
- `source_url`
- `source_authority = official`
- `published_at` 或頁面最新修改日期
- `checked_at`
- `effective_from` 與 `effective_to`
- `content_hash`
- `enforcement_level`
- `affected_modules`

每週檢查官方公告及關鍵規則頁是否變更；每次產生建議時保存使用的規則版本。規則變更後只重算受影響的候選，不重跑全部歷史資料。
