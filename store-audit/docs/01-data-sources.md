# 資料來源清單

## 狀態定義

- **已確認**：現有資料已證明來源、核心欄位和穩定識別碼可取得。
- **部分確認**：已能取得資料，但仍有 Key、期間或完整性問題。
- **待確認**：目前沒有可用資料，正式建庫前需要小樣本驗證。

| 資料域 | 來源頁面或來源 | 目前狀態 | 已知內容 | 主要缺口 |

| 商品清單 | 我的商品 | 已確認 | `productId`、名稱、主商品貨號、過去 30 天銷量、過去 30 天瀏覽量、累計售出、商品網址 | 價格、庫存及狀態仍需正式欄位確認 |
| 賣家數據中心－商品表現 | 賣家數據中心 | 待小樣本確認 | 預計讀取每日商品自然瀏覽、加購、訂單與轉換；欄位以實際頁面為準 | 必須確認自然流量口徑、可查日期範圍與匯出／分頁方式 |
| 賣家數據中心－賣場總覽 | 賣家數據中心 | 待小樣本確認 | 預計讀取訪客、瀏覽、訂單、轉換與客單價 | 只作賣場趨勢，不可直接分配到單品 |

| 優惠券 | 優惠券列表 | 部分確認 | 狀態、名稱、代碼、類型、適用商品、折扣、發放量、使用量及期間 | 穩定活動 ID 尚未確認；代碼不能預設為永不變更 |

| 物流限制 | 商品重量、尺寸及店內規則 | 待確認 | 現有標準化資料未包含 | 商品組合需判斷同箱、超材及運費風險 |

## 已確認的現有資料量

- 商品：1,338 筆。
- 商品 `productId`：1,338 個非空唯一值。
- 商品 SKU：1,318 個唯一值，存在 20 筆重複，因此不能作為 Key。
- 商品規格關係：3,638 筆；`variationId` 皆唯一，沒有跨商品衝突。
- 廣告：1,869 筆。
- 廣告網址可解析 `adId`：1,869 筆，當前樣本中全部唯一。
- 促銷詳情網址包含活動 ID，例如 `/discount/{id}` 和 `/bundle/{id}`。

## 建議同步頻率

| 資料 | 正式系統建議頻率 | 備註 |
|---|---|---|
| 店鋪基本資料 | 每週或發現變更時 | 不需要每日完整保存 |
| 商品身份及內容 | 每日一次 | 內容相同只更新最後看到時間 |
| 商品自然流量明細 | 每日增量 | 保存 `metric_date`；由每日明細計算 30／60 日窗口，不重抓已完成日期 |
| 賣場總覽 | 每日 D-1 | 只保存結構化指標；用於判斷全店異常，不代替商品層數據 |
| 進行中廣告指標 | 每日一次 | 區分單品廣告及群組廣告，保存來源統計期間 |
| 全部廣告狀態 | 每週一次 | 只核對啟停、結束及刪除狀態，不讀取所有詳情 |
| 促銷及優惠券 | 每日一次 | 即將開始或到期活動可提高頻率 |
| 訂單商品明細 | 依最後訂單時間增量 | 只讀取新增或更新訂單 |
| 成本 | 有變更時 | 必須保留生效期間 |
| 全量核對 | 每週一次 | 用於偵測漏讀、刪除及下架 |

## 資料最小化

- 訂單分析只保存匿名訂單識別碼和商品明細，不保存非必要買家姓名、電話或地址。
- 原始頁面只作為證據及重新解析來源，不直接交給模型。
- 正式資料庫不反覆保存完整頁面文字。
- 不能支援商品、廣告、促銷、加購或效果追蹤決策的欄位，預設不收集。
