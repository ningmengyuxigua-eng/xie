# 商品分析正式報表維度契約

## 報表定位

目前的 PPT 是案例版，只用來確認版型和分析流程。正式商品報表必須先通過資料完整度檢查；缺少核心欄位時只輸出資料缺口，不輸出可執行的商品去留、廣告、組合或定價建議。

機器可讀規則位於 `config/product-analysis-report-contract.json`。

## 固定粒度與 Key

- 商品主鍵：`store_id + product_id`。
- 規格主鍵：`store_id + product_id + variation_id`。
- 商品期間報表粒度：每個 `store_id + product_id + period_end` 一列。
- 每日流量觀測主鍵：`store_id + product_id + metric_date + traffic_scope`。
- `traffic_scope` 只允許 `legacy_views30`、`natural`、`advertising`、`unknown`。

## 三種流量口徑

1. `legacy_views30`：舊商品清單的 `views30`。只能作候選篩選，不能填入自然瀏覽或廣告指標。
2. `natural`：賣家數據中心確認為非廣告的商品瀏覽。正式的 30／60 日自然瀏覽必須由此來源或其每日明細計算。
3. `advertising`：廣告後台的曝光、點擊、花費、訂單與廣告營收。不得計入自然瀏覽。

來源不清楚時保存為 `unknown`，缺失值保持 `null`，不能當成 0。

## 十個基礎維度

| 維度 | 核心內容 | 主要用途 |
|---|---|---|
| 商品身份 | 店鋪、商品 ID、規格 ID、名稱、SKU | 去重與跨來源關聯 |
| 生命週期 | 上架狀態、上架時間、商品年齡、首次及最後看到時間 | 區分新品、成熟品與下架品 |
| 類目與角色 | 平台類目、店內角色、季節性、人工保留原因 | 判斷店鋪適配與去留例外 |
| 價格與庫存 | 當前價格、參考價、庫存、可售狀態、成本 | 定價、庫存與毛利風險 |
| 自然流量 | D-1、7／30／60 日自然瀏覽、加購、訂單、轉換 | 判斷自然需求與商品頁效率 |
| 廣告 | 當前狀態、類型、群組、7／30 日曝光至 ROAS | 判斷付費流量效率 |
| 銷售 | 7／30／60 日銷量、訂單、營收、退款、累計售出 | 判斷商品貢獻與趨勢 |
| 促銷 | 折扣、組合、加價購、優惠券及商品角色 | 避免誤判被活動承接的商品 |
| 台灣市場適配 | 關鍵詞、競品樣本、價格帶、規格與在地化問題 | 支持保留、優化或退出理由 |
| 資料品質 | 期間、截止時間、來源、覆蓋天數、缺失欄位與規則版本 | 決定能否生成正式報表 |

## 報表等級

### 案例版

- 可以用舊快照展示版型與候選排序。
- 必須顯示「案例／資料未齊」。
- 不得輸出下架、停廣告或確定價格等可執行結論。

### 部分資料版

- 商品身份、上架、價格、庫存與銷售資料已齊，但自然流量、廣告或促銷仍有缺口。
- 可以輸出資料缺口和讀取優先級。
- 不得輸出正式推薦。

### 正式版

- `requiredFieldSets.final` 中的欄位完整率必須為 100%。
- 60 日自然零瀏覽判斷必須有完整 60 日資料覆蓋；商品上架未滿 60 天時標記 `not_applicable`。
- 每個商品的廣告狀態必須是明確的 `active`、`inactive` 或 `none`，不能用舊映射數量替代。
- 當前價格、庫存、上架狀態、銷售及促銷狀態必須與報表截止時間一致。
- 只有正式版可以產生商品保留、優化、組合／加價購、停止廣告測試或人工下架審核建議。

### 正式商業建議

定價、組合銷售及加價購建議還要補齊成本、平台費用、運費增量及台灣競品價格帶。缺少成本時只能提供測試規則，不能提供確定售價。

## 缺失值與零值

- `null`：尚未取得或取得失敗。
- `unknown`：已取得欄位，但來源口徑無法確認。
- `not_applicable`：依規則不適用，例如上架未滿 60 天的 60 日指標。
- `0`：來源期間完整且明確回傳為零。

不得用 0 代替 `null`、`unknown` 或 `not_applicable`。

## 生成前檢查

正式生成器必須先輸出：

1. 商品總數與納入商品數。
2. 每個必填欄位的完整率。
3. 缺失欄位及受影響商品 ID。
4. 日期覆蓋、來源名稱、資料截止時間及來源指紋。
5. 報表等級判定及被阻擋的結論類型。

未通過正式版門檻時，生成器只保存 `data-gap.json`、`data-gap.md` 與進度 checkpoint，不生成正式 PPT、PDF 或可執行建議。
